# Supermercado La Canasta — Taller 3

Proyecto de práctica para principiantes. Requiere Docker Desktop y Docker Compose.

## Iniciar
```bash
docker compose up --build
```
Luego visita:
- Web: http://localhost:5000
- Documentación de la API: http://localhost:8000/docs

## Detener
```bash
docker compose down
```

La API crea automáticamente las tablas y carga productos de ejemplo en una base de datos vacía.
Las claves del archivo son solo de demostración; no las uses en producción.
